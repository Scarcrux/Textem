Verification codes

Copy a code from a text in one click, or pick it from AutoFill in Safari.

On this page

  • Copy Code on the notification
  • Copy from a conversation or another app
  • Textem Codes in AutoFill Experimental · macOS 15+

Copy Code on the notification

When a text with a verification code arrives, its notification gets a Copy Code button. Click it, then paste where you need the code.

  • A code can be copied for 3 minutes after it arrives.
  • Codes stay in memory only, and are copied marked as private so clipboard managers that respect that don't save them.
  • To copy the most recent code at any time, choose Edit > Copy Latest Code (⇧⌘C).
  • To turn the button off: Textem > Settings… > Verification Codes > Copy Code button in notifications.

Detection is cautious: it needs verification wording and exactly one 4–8 digit code, and ignores your own messages, promo codes, phone numbers and amounts. Notifications only offer newly received codes.

Copy from a conversation or another app

If the open conversation contains a detected verification code, choose Copy Code or use Show Message to find the original text. Check the age before using the code.

To copy a fresh code while you are in another app, turn on Global Copy Latest Code shortcut in Settings > Verification Codes. Choose Change Shortcut…, press a letter or number with at least two modifiers including Command or Control, then click Save. The global shortcut uses codes received in the active Textem account in the last three minutes.

Textem Codes in AutoFill Experimental · macOS 15+

Textem can also offer fresh codes in Safari's AutoFill, the way Apple's Messages app does. This is experimental and hasn't yet been confirmed showing up in every app.

  1. Open System Settings > General > AutoFill & Passwords and turn on Textem Codes.
  2. In Textem > Settings… > Verification Codes, turn on AutoFill verification codes (Experimental).
  3. When a site asks for a code, click the code field, open AutoFill and choose Textem Codes, then the code.

If the text ends in the form @example.com #123456, macOS can also suggest that code directly on example.com. Apple's own "From Messages" suggestions only read Apple's Messages and Mail apps, so Textem uses Apple's AutoFill provider system instead.

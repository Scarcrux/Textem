Install Textem

Download the signed app, move it to Applications, and allow notifications.

On this page

  • Before you start
  • Download and install
  • Allow notifications
  • Keep it up to date

Before you start

  • A Mac with macOS 13 (Ventura) or later, Apple silicon or Intel.
  • An Android phone with Google Messages, signed in to a Google account.
  • Multiple Google accounts need macOS 14 or later; Textem Codes in AutoFill needs macOS 15 or later.

Textem is a free, unofficial macOS wrapper for Google Messages for web. It shows Google's own web client in a Mac window and adds notifications, a Dock badge, shortcuts and more.

Download and install

  1. Download Textem.dmg.
  2. Open the disk image and drag Textem onto Applications.
  3. Open Textem from Applications. It is signed with a Developer ID and notarized by Apple, so it opens without a security warning.

Allow notifications

The first time Textem runs, macOS asks whether it may send notifications. Choose Allow so new texts show up as banners you can reply to. You can change this later in System Settings > Notifications > Textem.

Keep it up to date

While it is open, Textem checks for a new version once a day and asks before installing anything. To check now, choose Textem > Check for Updates…. To turn the daily check off, open Textem > Settings… (⌘,) and switch off Automatically check for updates.

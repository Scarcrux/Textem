Accounts, menu bar and shortcuts

Use more than one Google account, run Textem from the menu bar, and learn the shortcuts.

On this page

  • Multiple Google accounts
  • Menu bar and background
  • Keyboard shortcuts

Multiple Google accounts

On macOS 14 or later, use the Accounts menu to Add Account…, switch between accounts, Rename Current Account… or Remove Current Account…. Each account keeps its own separate session, so you pair each one once.

Menu bar and background

The menu-bar icon shows your unread count. Its menu has Show Textem, your accounts, Settings…, and quick switches for Launch at Login, Menu Bar Only, Mute Notifications and Quit When Window Closed.

The same choices are in Textem > Settings… under General: Launch at login, Start hidden, Menu bar only (hides the Dock icon) and Quit when the window is closed.

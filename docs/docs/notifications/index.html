Notifications and quick replies

See new texts as notifications, reply without opening Textem, and control what a banner shows.

On this page

  • New-message notifications
  • Reply from the notification
  • Mute or hide what banners show
  • Test that notifications work

New-message notifications

When a text arrives and Textem isn't the frontmost app, a notification shows the sender and the message. Click it to open that exact conversation. The Dock icon and the menu-bar icon show your unread count.

Reply from the notification

  1. Hover over the notification and click Reply.
  2. Type your reply and press Return.

Textem sends it to the conversation the notification came from, even if a different one is open. If Textem can't confirm the message went out, it says Reply status unknown — check the thread before resending, so you don't send it twice.

Mute or hide what banners show

In Textem > Settings…, under Notifications:

  • Mute notifications stops banners. The Dock badge still updates.
  • Hide sender and message preview shows only "New message".

Mute is also in the menu-bar icon's menu.

Test that notifications work

Choose Help > Diagnostics > Send Test Notification. If no banner appears, see No notifications.

What’s New

Release highlights, update instructions, and downloads for Textem.

November 24, 2026 · Latest

1.0 public beta 6

Important fix for App Lock. In betas 4 and 5, a locked Textem stopped receiving messages, so no notifications arrived until you unlocked. Textem now keeps receiving messages while locked and notifies you without showing the sender or text. The lock screen still covers everything, and the hidden page can’t be clicked, typed into or read by VoiceOver.

On beta 2 or later, choose Textem → Check for Updates…. On beta 1, download the new app and replace the old copy in Applications.

November 24, 2026

1.0 public beta 5

  • While Textem is locked, notifications no longer show a Copy Code button, so a locked banner never reveals that a code arrived. Reply stays and asks you to unlock first.
  • App Lock has its own section in Settings, which explains what locking does: notifications are cleared, the unread count stays, and your files rely on your Mac login and FileVault.
  • The lock screen leads with Touch ID when your Mac has it, and asks only for your password when it doesn’t.
  • The global copy-code shortcut unlocks with the macOS prompt without bringing Textem to the front.
  • The sign-in guide can be closed, Delete Saved AutoFill Codes… asks before deleting, and AutoFill messages in Settings are in plain language.

On beta 2, 3 or 4, choose Textem → Check for Updates…. On beta 1, download the new app and replace the old copy in Applications.

1.0 public beta 4

  • Lock the Textem window with Touch ID or your Mac password. Choose when it locks in Settings → Privacy.
  • Copy a verification code from an open conversation, or set your own global shortcut in Settings → Verification Codes.
  • Notification clicks return to the original conversation after unlock. If locking interrupts a reply, Textem tells you when its send status is uncertain.

On beta 2 or 3, choose Textem → Check for Updates…. On beta 1, download the new app and replace the old copy in Applications.
